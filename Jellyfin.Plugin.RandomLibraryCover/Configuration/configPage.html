Random Library Cover

Hover over a library in My Media on the home screen, open the ⋮ menu and choose Random cover to give it a new cover from its own artwork. Covers are shared by all users, so only administrators see the menu item.

Both are landscape like the library cards. Backdrops are plain artwork, thumbs usually have the title on them.
Darkens the image and puts the library name on it in large white letters, like Jellyfin's own generated covers.

Automatic shuffle

Unchecked libraries keep their cover until you change it from the menu. New libraries are included.
